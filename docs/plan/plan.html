Phase 6

Ecrin Wallet: Chrome extension, then mobile app

A wallet where savings live in the vault by default and only a small allowance is spendable.

How it's built

  • One shared core in TypeScript: keys, Solana and Ethereum support, the Ecrin vault client (chain.js / evm.js already exist), and a check of every transaction before signing.
  • Chrome extension (Manifest V3): the key is stored encrypted with a password; websites see it the same way they see Phantom and MetaMask, so dApps work with it. React popup.
  • Mobile app (React Native with Expo): keys in the phone's secure storage (Keychain / Keystore) behind Face ID or a fingerprint. Not a wrapped website: that's weaker for holding keys.
  • What makes it Ecrin: vault by default, spending allowance, every outgoing transaction explained in plain words before you sign ("this goes to a new address and will wait 72 h"), cancel and alerts built in.

Rules that don't change

  • No real money before the independent audit.
  • Never paste private keys, seed phrases or API keys into chat or GitHub; secrets go into Cloudflare or GitHub secrets only. Testnet keys stay testnet-only.
  • Every contract change gets tests first, and goes into the next audit.
  • Be honest on the site: audit status, test coins, and that Circle can freeze USDC.

This plan will change as testers give feedback. Ask for a new version any time.
